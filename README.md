A 4 KB Python chess engine for make.fun's tiny-chess-01: a PeSTO evaluation with PVS, a transposition table and quiescence, plus a prepared book for the practice instance's six games. `main.py` is the packed entry; `engine.py` is its readable source.

Run: `python3 main.py` with `MAKEFUN_ENV_URL` set to the trial env.
